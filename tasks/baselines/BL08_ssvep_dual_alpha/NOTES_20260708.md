# 2026-07-08 Dual-Alpha Baseline Notes

## Dataset

- Local root: `D:/ProjData/datasets/ssvep_dual_alpha_gigadb_102557`.
- Public packages:
  - `Checkerboard_Arrangment.tar.gz`: 35 subjects, 9 channels.
  - `Binocular_Vision.tar.gz`: 35 subjects, 9 channels.
  - `Binocular-Swap_Vision.tar.gz`: 35 subjects, 64 channels.
- Each subject has 40 targets x 5 epochs. Sampling rate is 250 Hz.

## Protocol

- Crop windows: `0.2:0.2:2.0`.
- CV: 5-block leave-one-block-out. For each fold, one epoch per class is tested and the other four epochs per class train TRCA/ETRCA.
- ITR: 40 classes, `trial_seconds = window + 0.5`, matching the public example script.
- Official TRCA uses ensemble mode. Arena labels this as `ETRCA` and may also run non-ensemble `TRCA` as an extension.

## Preprocessing Contrast With Ke AR

- Dual-Alpha: already epoch-level CSV; crop from the first sample of each epoch; apply method-specific filterbank after crop.
- Ke 2025 Binocular AR: BIDS-like continuous EEG; Arena performs continuous demeaning, 49-51 Hz notch, 5-95 Hz bandpass, and event onset + 0.14 s epoching before the task filterbank.
- The classifier-facing tensor becomes similar, but the preprocessing entrance is not the same.

## Official References

- `source_code/trca_process.py`: public ensemble TRCA baseline with 7 Chebyshev filter-bank subbands.
- `source_code/fbdcca_process.py`: public FBDCCA baseline for CA/BV with dual-frequency templates, squared correlations, fixed weights, and 5 active subbands in the default call.
- `metadata/Classification_results_of_TRCA.csv` and `metadata/Classification_results_of_FBDCCA.csv`: official result tables used for coarse validation.
