# Liang 2020 Dual-Frequency TDCA Diagnostic Full Run

## Status

The full diagnostic TDCA run is complete. It evaluates every available subject
for the two conditions governed by the Method 1 codebook digitized from Figure
1(a): Exp3 condition 3 and Exp4 condition 1.

This is not an official paper reproduction. The public MAT labels do not use
the Figure 1 row-major target order, so the Figure 1 codebook was aligned once
to Exp3 S1 spectra and then frozen. The main aggregate excludes S1, which was
used only to calibrate that mapping. An author-confirmed MAT-label codebook is
still required before promoting this TDCA path to a formal result.

The Exp4 count is intentionally not forced to a common denominator. S2 contains
two test runs with 80 trials each (runs 7 and 8) and no run 9; the other 11
subjects contain runs 7-9 with 40 trials each. Per-subject accuracies are
computed before the aggregate mean, so S2 does not receive extra group weight.
The paper's Table 4 also reports S2's online accuracy in 0.625% increments,
consistent with 160 trials.

## Main Result

The external-subject aggregate excludes S1. Accuracy is a mean over the 11
remaining subjects, with SEM in the rendered curves.

| Evaluation | 0.2 s | 0.4 s | 0.6 s | 1.0 s |
|---|---:|---:|---:|---:|
| Exp3 Method 1 TDCA | 67.78% | 81.82% | 87.78% | 93.92% |
| Exp4 Method 1 TDCA | 38.35% | 51.40% | 59.79% | 70.11% |

Exp3 reaches 97.59% at 2.0 s. The Exp4 values are an offline TDCA diagnostic
using the paper's run split, not the paper's online TRCA-feedback result; they
must not be compared as equivalent implementations.
