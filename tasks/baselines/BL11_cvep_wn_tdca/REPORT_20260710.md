## 预处理与方法

主复现脚本：

```text
tasks/cvep_broadband_white_noise_tdca/run_reference_tdca.py
```

该脚本直接导入 Zenodo `core/spatialFilters.py` 中的 `TDCA` 类，配置为：

- channels: `paper21`
- `n_band=5`
- `lag=0.14`
- `montage=160`
- 每个窗口独立运行 6 折 leave-one-repetition-out

当前 Arena `.venv` 没有安装 `statsmodels`，因此脚本提供了一个很小的 `statsmodels.stats.weightstats.ttest_ind` shim。这个 shim 只用于作者代码在预测后计算 confidence/p-value，不参与 `fit`、`predict` 或分类决策。

全量运行命令：

```powershell
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:NUMEXPR_NUM_THREADS='1'
.\.venv\Scripts\python.exe tasks\cvep_broadband_white_noise_tdca\run_reference_tdca.py --subjects all --sessions all --windows 0.1,0.2,0.3,0.4 --max-folds 0 --output results\reference_tdca_full
```

准确率随窗口长度单调上升，0.4s 达到 98.8%。ITR 的峰值在 0.3s，因为 0.4s 的额外准确率提升不足以抵消更长窗口。

0.1s 下准确率已经达到 49.9%，远高于 160 类 chance level 0.625%。这说明 WN 宽带序列在极短窗口内已经提供了很强的判别信息。

## 方法备注

Zenodo `classification.py` 的识别调用是：

```python
model = TDCA(winLEN=winLEN, lag=lag, srate=srate, montage=targetNUM, n_band=n_band)
model.fit(X_train, y_train)
model.score(X_test, y_test)
```

也就是说，作者 TDCA 路径没有把 `STI.mat` 或 WN 原始刺激序列作为 TDCA reference 传入。它使用训练 EEG 的 class evoked/template，并通过宽频 filter bank 和 Fisher-style 空间滤波完成分类。

Arena 标准 `vep_arena.methods.tdca.TDCA` 也会使用训练 EEG 构建 class templates；差异在于 Arena 标准 TDCA 还需要 `refs` 构造 reference projection 子空间，并带有标准 SSVEP TDCA 的 delay augmentation 入口。因此，在 WN-BCI 上直接用原始 WN sequence 当 `refs` 是一个 ablation，不等价于作者 TDCA。

已有 sanity check：

| 实现 | 配置 | 正确数 | Acc |
|------|------|-------:|----:|
| HD legacy TDCA | S1, 40 targets, 9ch, 200ms | 705/720 | 97.9% |
| `vep_arena.methods.tdca.TDCA` | 同配置 | 709/720 | 98.5% |

这说明共享 TDCA 没有明显整体实现错误；WN-BCI 的差异主要来自范式和作者 TDCA 变体，而不是 Arena TDCA 在 SSVEP 任务上失效。

## SSVEP 分支检查

Zenodo 代码中有 SSVEP 占位：

- `core/classification.py`: `tags = ['WN', 'SSVEP']`
- `info/mutualINFO.py`: `tags = ['WN', 'SSVEP']`

但当前公开包没有可运行的 SSVEP 数据：

- `data/seperate/sweep/S_*.pkl` 存在，tag 全是 `WN`。
- `data/seperate/compare` 为空。
- `data/stimulation/compare` 只有 `.DS_Store`。
- `data/datasets` 只有 `.DS_Store`，没有 `sweep.pickle` 或 compare 数据。

因此，Zenodo 8300517 当前只能支持 WN sweep 复现。MFSC160 应作为相关但独立的 160-target SSVEP 数据集处理。
