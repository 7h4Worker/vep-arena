# NOTES 2026-07-09

## Scope

Started a task-owned smoke workflow for the Sun2024 efficient dual-frequency dataset. This is the newer public dual-frequency dataset with binocular left/right-eye frequency codebooks.

## Dataset Checks

- Local root: `D:/ProjData/datasets/ssvep_efficient_dual_frequency_sun2024`.
- `metadata/README.txt` cites Sun et al. 2024, Expert Systems with Applications, DOI `10.1016/j.eswa.2024.124144`.
- Extracted files include `Data of 1Target`, `Data of 40targets offline`, and two Excel codebooks.
- MNE can read `.cnt` headers directly in the Arena `.venv`.
- Subject 01 40-target file has 64 channels, 1000 Hz, and annotations for triggers 1-40 plus 253 stimulus-end markers.
- The Excel parser uses stdlib ZIP/XML because `openpyxl` is not part of the Arena `.venv`.
