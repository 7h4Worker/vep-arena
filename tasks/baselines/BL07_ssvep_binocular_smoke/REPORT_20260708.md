## 3. 预处理差异

两个数据集进入分类器后的张量形式相近，但前处理入口不同：

- Dual-Alpha：公开数据已经是 epoch CSV；直接裁剪窗口，再做方法滤波器组。
- Ke AR：公开数据是连续 EEG + events；需要连续去均值、50 Hz 陷波、5-95 Hz 带通，再按 event onset + 0.14s 切窗。

因此不能把两者称为“完全一样的预处理”，只能说分类协议和 filter-bank/TRCA 接口已经尽量统一。
