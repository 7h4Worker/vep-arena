# 20260707 Benchmark decision-channel task structure note

## Current role

This task is the main decision-channel capacity reproduction and analysis task.
It connects Benchmark-style predictions to information-theoretic quantities and
figures.

## Current source files

- `run.py`
  - Produces or collects task input predictions.
- `analyze.py`
  - Builds confusion matrices and capacity tables.
- `plot.py`
  - Produces the task figures.
- `report_zh.md`
  - Chinese report draft combining formulas, results, and interpretation.
- `README.md`
  - Task entrypoint and command reference.

## Current result layout

- `results/input`
  - Input predictions or copied source summaries.
- `results/analysis`
  - Capacity tables, confusion matrices, and derived metrics.
- `results/figures`
  - Generated figures for the report.

No legacy movement was needed on 20260707. This task already has a compact
source layout. The main next step is to make the input source explicit for each
