# SSVEP-BCI Channel Sounding 研究方向笔记

> **日期**: 2026-07-08
> **性质**: 研究方向备忘，非正式报告
> **来源**: 决策信道分析框架推导出的应用方向

---

## 0. 定位

Channel sounding 是本项目决策信道分析框架的一个下游应用方向。分析框架提供了量化信道状态的工具（混淆矩阵 → P(Y|X) → MI），channel sounding 的问题是：**能否用最少的观测时间获取足够的信道状态信息 (CSI)，以指导解码策略选择？**

与 calibration 的根本区别：

```
Calibration:  学习静态解码参数 (空间滤波器, 模板)
              需要每个目标的多次重复 trial
              假设信道在使用期间不变

Channel sounding:  感知当前信道状态
              用最少观测覆盖状态空间
              产出 CSI 向量 (频率可用性, 整体 SNR 等级, 干扰位置)
              信道状态会变，需要周期性或触发式更新
```

## 1. 与无线通信 channel sounding 的类比

### 1.1 最接近的类比：认知无线电频谱感知

| 认知无线电 | SSVEP-BCI |
|-----------|-----------|
| 主用户信号（要避开） | Alpha/theta 内源震荡（个体中心频率 8-13 Hz） |
| 频谱空洞（可用频段） | SSVEP 响应好的频率 |
| 邻信道泄漏 | 相邻目标视觉串扰（空间排列依赖） |
| 感知时间 vs 检测概率权衡 | Sounding 时长 vs 信道估计精度 |
| 目标：快速判断"哪里能用" | 目标：快速判断"哪些频率当前可靠" |

### 1.2 其他无线技术的映射

- **OFDM 导频**：稀疏频率采样 + 插值。对 SSVEP 部分适用，但信道不完全平滑（有 alpha 窄带干扰）。
- **Beam sweeping (5G mmWave)**：扫描方向快速选最优 beam。对应 SSVEP 的频率/空间配置快速扫描。
- **WiFi CSI from preamble**：每个 packet 自动提取 CSI。对应 BCI 每个 trial 的在线 CSI 更新。

### 1.3 关键差异

SSVEP 信道不是平滑频率响应——存在：
- **个体化窄带干扰**：alpha 震荡中心频率因人而异 (8-13 Hz)，在 SSVEP 频率范围内制造干扰凹口
- **空间排列串扰**：相邻目标的视觉刺激通过周边视觉串入，c-VEP 中随机序列相似时尤为明显
- **频段特异性**：某些被试特定频段强/弱，可能与视觉皮层共振频率有关，非平滑可预测
- **时变性**：注意力、疲劳、电极漂移等在不同时间尺度上改变信道状态

## 2. 初步协议设想

```
Phase 1 — 被动感知 (无刺激, ~5秒)
  └ 记录静息态 EEG
  └ 提取: alpha peak 频率/功率, 1/f slope, 通道质量
  └ 产出: 干扰图谱 (哪些频率有内源活动)
  └ 类比: 认知无线电的 quiet period spectrum sensing

Phase 2 — 主动探测 (~3-5秒)
  └ 呈现少量 sounding 刺激 (选频或编码设计)
  └ 选择依据: 避开 Phase 1 发现的干扰频段
  └ 提取: SSVEP 响应幅度, SNR, 空间模式
  └ 产出: 信道等级 + 解码策略推荐

Phase 3 — 在线跟踪 (持续)
  └ 从每个实际 trial 提取 CSI 更新
  └ 检测信道退化 → 触发 re-sounding
```

## 3. 需要的验证数据

现有数据能部分验证：
- Wearable 数据集 per-subject per-target 结果可用于模拟 pilot 频率选择效果
- Per-subject MI 分布 (0.1-3.5 bits) 可用于验证"几秒 sounding 能否预测整体信道等级"

完整验证需要：
- 包含 resting-state + SSVEP 配对的数据集
- 不同时间点的重复测量（用于评估信道相干时间）

## 4. 与当前分析框架的关系

Channel sounding 依赖的分析工具：
- 混淆矩阵计算 → 信道矩阵 P(Y|X) (Script 21/23)
- MI 计算 → 信道容量度量
- 预处理分析 → 理解 FB 对信道的塑形效应 (Script 22)
- 方法反转发现 → 解码策略选择的依据

**Channel sounding 是分析框架的应用出口，而非独立的分析方法。**
