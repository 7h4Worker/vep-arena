# SSVEP-BCI 预处理流水线与滤波器组分析

> **日期**: 2026-07-05
> **脚本**: `scripts/22_filterbank_frequency_response.py`
> **代码位置**: `vep_arena/data/benchmark.py`, `vep_arena/data/epochs.py`, `vep_arena/methods/`
> **适用范围**: Benchmark (40-target, 9ch/64ch) 与 HD200 (200-target, 66ch) 共用

---

## 0. 目的

本报告记录 vep_arena 项目中各 SSVEP 解码方法实际使用的预处理流水线，分析滤波器组 (Filter Bank, FB) 的 DSP 特性及其对信道分析的潜在影响。

核心结论：**滤波器组不是中性预处理——它改变了各频率目标的相对增益，即改变了解码器"看到"的信道条件。** 如果要追究本体的信道特性，FB 本身会成为一个需要分离的变量。

## 1. 预处理流水线架构

### 1.0 数据集自带的硬件级预处理

.mat 文件到达代码之前，数据集本身已经做了硬件和发布前处理。这是整个处理链的"第零层"。

**Benchmark 数据集** (Wang et al. 2016, 40-target, 35 subjects)：

| 层级 | 操作 | 参数 |
|------|------|------|
| 采集硬件 | 模拟带通 | **0.15 – 200 Hz** (Synamps2 放大器通带) |
| 采集硬件 | 50 Hz 陷波 | 录制时施加，去除工频干扰 |
| 发布前处理 | 分段 | 6 s epochs (0.5 s pre-stim + 5.5 s post) |
| 发布前处理 | 降采样 | 1000 → **250 Hz** |
| 发布前处理 | 无额外数字滤波 | .mat 中存储 double 精度浮点 |

来源：`D:/ProjData/datasets/ssvep_benchmark/Readme.txt`

**HD200 数据集** (Ming et al. 2026, 200-target, 14 subjects)：

具体硬件参数需查原论文 (arXiv:2507.17242)，但实验范式类似，预期同样有硬件级模拟带通和 50 Hz 陷波。本项目使用的是 TDCA 缓存格式 (`filtered_S{n}_200target_66ch_18blocks_float32.npy`)，已包含 5 子带滤波器组处理。

**重要注意**：数据集已包含硬件 50 Hz 陷波 → 我们的代码又施加了一次软件 50 Hz 陷波 (`iircomb`) = **双重陷波**。虽然第二次陷波在已衰减的 50 Hz 处作用很小，但严格来说是冗余操作，可能在 50 Hz 附近引入额外的微小凹陷。对 SSVEP 分析无实质影响（没有目标频率的谐波恰好落在 50.0 Hz），但应当记录这一事实。

### 1.1 软件预处理核心

在数据集硬件预处理之上，所有传统方法共享两级软件预处理（代码位于 `vep_arena/data/benchmark.py`）：

```
.mat 数据 (已含硬件带通 0.15-200 Hz + 硬件 50Hz 陷波 + 降采样 250 Hz)
  │
  ├─ 提取时间段: cue_offset (0.5s) 到 cue_offset + latency (0.14s) + window + extra_samples
  │
  ├─ 第一级: 50 Hz IIR 梳状陷波 (软件, 第二次)
  │    signal.iircomb(50, Q=35, ftype="notch", fs=250)
  │    filtfilt (零相位), padtype="odd", padlen=3×(filter_order-1)
  │
  ├─ 第二级 (仅 FB 方法): Chebyshev I 带通滤波器组
  │    5 子带, cheb1ord + cheby1, filtfilt
  │
  └─ 延迟裁剪: 去掉前 0.14s (35 samples) visual latency
       → 最终 epoch: (channels, samples)  或  (subbands, channels, samples)
```

**完整的端到端滤波链**：

```
CCA 的实际输入:
  硬件带通 (0.15-200 Hz) → 降采样 (250 Hz, Nyquist=125 Hz) → 软件陷波 (50 Hz)
  → 有效频带: 0.15 – 125 Hz, 50 Hz 被双重衰减

FBCCA/TRCA 的实际输入:
  硬件带通 → 降采样 → 软件陷波 → FB0: Cheby I 带通 (8-90 Hz)
  → 有效频带: 8 – 90 Hz, 50 Hz 被三重衰减 (硬件+软件+FB 通带内)
```

**关键设计**：软件滤波在延迟裁剪之前完成——即 notch 和 filterbank 作用于包含 latency 的完整段，滤波后再裁剪。这减少了短窗口下的边缘效应。

### 1.2 各方法的预处理路径

| 方法 | 陷波 | 滤波器组 | 输入格式 | 代码路径 |
|------|------|---------|---------|---------|
| **CCA** | 50 Hz | **无** (kind="raw") | (trials, 1, ch, samples) | `load_subject_toolbox_raw()` |
| **FBCCA** | 50 Hz | 5 子带 Cheby I | (trials, 5, ch, samples) | `load_subject_filterbank()` |
| **TRCA / eTRCA** | 50 Hz | 5 子带 Cheby I | (trials, 5, ch, samples) | 同上 |
| **ECCA** | 50 Hz | 5 子带 Cheby I | (trials, 5, ch, samples) | 同上 |
| **SSCOR / ESSCOR** | 50 Hz | 5 子带 Cheby I | (trials, 5, ch, samples) | 同上 |
| **TDCA** | 50 Hz | 5 子带 Cheby I + extra_samples | (trials, 5, ch, samples+delay) | 同上, extra_samples>0 |
| **SSVEPFormer** | — | 3 子带 Butterworth 4阶, 在线 | 模型内部处理 | `nn/ssvepformer.py` |
| **EEGNet** | — | **无** | (batch, 1, ch, samples) | `nn/eegnet.py` |
| **TRCANet** | — | 3 子带 Cheby I | 预处理 | `methods/trcanet.py` |

**CCA 的特殊性**：CCA 不使用任何带通滤波。它的频率选择性完全来自算法内部——CCA 与 sin/cos 参考信号求典型相关，本质上是对目标频率的匹配滤波。这意味着 CCA 的输入包含完整频带（0-125 Hz，仅去除 50 Hz 陷波），包括 0-8 Hz 的低频 EEG 噪声（alpha/theta 节律、1/f 背景）。

## 2. 滤波器组参数详表

### 2.1 Benchmark 标准滤波器组 (FBCCA / TRCA / ECCA / SSCOR)

代码位置：`vep_arena/data/benchmark.py:86-111`

| 子带 | 通带 (Hz) | 阻带 (Hz) | 滤波器阶数 | 权重 w(k) |
|------|----------|----------|-----------|----------|
| FB0 | 8 – 90 | 6 / 100 | 7 | 1.2500 |
| FB1 | 16 – 90 | 14 / 100 | 10 | 0.6704 |
| FB2 | 24 – 90 | 22 / 100 | 11 | 0.5033 |
| FB3 | 32 – 90 | 30 / 100 | 12 | 0.4268 |
| FB4 | 40 – 90 | 38 / 100 | 12 | 0.3837 |

**设计规格**：
- 滤波器类型：Chebyshev Type I（等纹波通带）
- 通带纹波：0.5 dB
- 阻带衰减：40 dB（自适应降低至 20 dB 如果 cheb1ord 设计失败）
- 零相位实现：`scipy.signal.filtfilt()`
- 上截频固定 90 Hz（Nyquist = 125 Hz）

**权重公式**（所有 FB 方法统一）：

```
w(k) = (k + 1)^{-1.25} + 0.25,    k = 0, 1, ..., 4

w = [1.250, 0.670, 0.503, 0.427, 0.384]
```

FB0 权重是 FB4 的 3.3 倍，意味着基波带信息被赋予最高权重。

### 2.2 其他滤波器组变体

**Nakanishi/Chen FBCCA** (`vep_arena/methods/cca.py:33-46`)：
- 10 子带（扩展版），通带起点 6/14/22/.../78 Hz
- 其余参数相同
- 仅在独立的 `run_cca_fbcca.py` 路径使用，非主线

**TRCANet** (`vep_arena/methods/trcanet.py:12-26`)：
- 3 子带，通带起点 6/14/22 Hz
- 相同的 Chebyshev I 设计

**FBSSVEPFormer** (`vep_arena/nn/ssvepformer.py:136-183`)：
- 3 子带：8-80 / 16-80 / 24-80 Hz
- **Butterworth 4 阶**（非 Chebyshev）
- 前向传播中在线滤波
- 上截频 80 Hz（非 90 Hz）

## 3. 滤波器组 DSP 特性分析

### 3.1 频响总览

![滤波器频响](../results/figures/fig_filterbank_response.png)

**Panel (a)**: 50 Hz 陷波在 50/100 Hz 处有窄深凹口（~-45 dB），Q=35 保证凹口足够窄不影响邻近频率的 SSVEP 信号。

**Panel (b)**: 5 子带的频响。注意 FB0 (order 7) 的过渡带比 FB1-4 (order 10-12) 宽——低阶滤波器在 6-8 Hz 过渡带内衰减不够陡峭。

**Panel (f)**: CCA vs FBCCA 输入对比——CCA 接收全频带（蓝色填充区），FBCCA 通过子带逐级去除低频。CCA 在 0-8 Hz 有完整的低频 EEG 噪声通过。

### 3.2 谐波覆盖率

**Panel (d)** 是关键：各子带对各次谐波的覆盖率。

```
         FB0    FB1    FB2    FB3    FB4
1f       100%   —      —      —      —
2f       100%   100%   49%    —      —
3f       100%   100%   100%   66%    32%
4f       100%   100%   100%   100%   74%
5f       100%   100%   100%   100%   100%
```

几个值得注意的不完全覆盖：
- **FB2 对 2f 仅 49%**：FB2 的截止频率 24 Hz 切入了二次谐波带 (16-31.6 Hz) 的中间。对于 8-11.8 Hz 的目标，2f 完全通过；对于 12-15.8 Hz 的目标，2f 被部分衰减。这意味着 **FB2 对低频和高频目标的谐波提取不对称**。
- **FB3 对 3f 仅 66%**：同理，FB3 截止 32 Hz 切入三次谐波带 (24-47.4 Hz)。
- **FB4 对 3f 仅 32%**：更极端，FB4 截止 40 Hz 仅保留 3f 带的上端。

### 3.3 群时延

**Panel (e)**：高阶滤波器 (FB1-4, order 10-12) 在通带边缘有显著的群时延（40-60 ms）。在通带中心群时延约 3-8 ms。

对于 SSVEP 解码这通常不是问题（因为 filtfilt 消除了线性相位延迟），但群时延不均匀意味着 **通带边缘附近的信号在时域上会有色散**，可能影响依赖精确时域波形的方法（如 TDCA 的时域增广）。

### 3.4 FB 对各目标频率的差异化影响

![滤波器组选择性](../results/figures/fig_filterbank_selectivity.png)

**Panel (a)**：各目标频率的 5 次谐波加权增益分解。三角标记 = CCA 增益（仅陷波），堆叠柱 = FBCCA 各子带贡献。

- CCA 的增益对所有频率几乎平坦（~5.0，仅因 50 Hz 陷波在 10.0 Hz 的 5f 处有微小凹陷）
- FBCCA 的总增益从 8 Hz 的 ~11.5 增长到 15.8 Hz 的 ~13.5
- 增长原因：高频目标的 2f/3f 谐波落在更多子带的通带内

**Panel (b)**：FBCCA/CCA 增益比。中位数 2.444，范围 2.3-2.8。**高频目标比低频目标获得更多 FB 增益**。

### 3.5 核心问题：FB 改变信道条件

FB 不仅仅是"去噪"——它系统性地改变了各频率目标之间的相对 SNR：

```
影响机制:

1. 低频切除: FB0 切 8 Hz 以下 → 去除 alpha/theta 噪声 → 所有频率受益
   但 CCA 看到的 0-8 Hz 噪声, FBCCA 看不到 → 两者的信道基线不同

2. 谐波差异化: 高频目标在更多子带中保留 2f/3f
   → 高频目标获得更多信息 → 频率间 SNR 不等

3. 子带权重: w(k) 衰减陡峭 (w0/w4 = 3.3x)
   → 基波信息主导, 高次谐波被压低但仍有贡献
   → 权重选择直接影响"信道"的频率选择性曲线

4. 过渡带效应: 子带截止频率处的部分衰减
   → 造成频率依赖的增益不均匀
   → 某些频率的某些谐波被"半通过"
```

**推论**：当我们用混淆矩阵计算 MI 来度量"信道容量"时，使用 FBCCA 解码器得到的 MI 不仅反映了物理信道，还包含了 FB 预处理引入的增益结构。要获得**纯物理信道的条件信道矩阵**，需要：
- 要么使用无 FB 的方法（CCA / 原始模板匹配）作为基线
- 要么系统地变化 FB 参数（子带数、截止频率、权重），观察 MI 如何随 FB 配置变化

这构成一个独立的研究分支。

## 4. 方法间预处理差异总结

### 4.1 传统方法内部

```
            陷波    滤波器组   时域增广   输入维度
CCA         ✓       ×          ×         ch × T
FBCCA       ✓       5 子带     ×         5 × ch × T
TRCA/eTRCA  ✓       5 子带     ×         5 × ch × T
ECCA        ✓       5 子带     ×         5 × ch × T
SSCOR       ✓       5 子带     ×         5 × ch × T
TDCA        ✓       5 子带     ✓(5 lag)  5 × ch × (T+5)
```

CCA 是唯一不使用 FB 的传统方法。这意味着 **CCA 和 FBCCA 的性能差距不纯粹是算法差异——输入信号就不同**。

### 4.2 传统 vs DNN

```
差异点        传统 (FBCCA/TRCA)        DNN (SSVEPFormer)
滤波器类型     Chebyshev I              Butterworth 4阶
子带数         5                        3
上截频         90 Hz                    80 Hz
滤波时机       离线预处理 (filtfilt)      前向传播 (在线, causal?)
权重来源       固定公式                  可学习参数
```

**Butterworth vs Chebyshev I**：Butterworth 在通带内完全平坦（maximally flat），而 Chebyshev I 有 0.5 dB 纹波。但 Chebyshev I 在同阶数下过渡带更陡，因此能用更低阶数达到相同的阻带衰减。

## 5. 对信道分析的影响与分支研究方向

### 5.1 当前分析中 FB 的角色

在 `benchmark_signal_channel_analysis` 的分析中，我们使用了两条路径：

1. **原始模板匹配**（Script 15/21）：直接在 FB0 滤波后的数据上做 Pearson 相关。这里 FB0 (8-90 Hz) 相当于宽带带通，已经去除了低频噪声。
2. **TDCA 分析**（来自 Codex 复现）：使用完整 5 子带 + 时域增广。

两条路径看到的"信道"不同。原始模板匹配用 FB0 单子带，相当于简单带通滤波后的物理信道；TDCA 用加权 5 子带，相当于经过匹配滤波的增强信道。

### 5.2 FB 作为独立研究变量

如果要精确测量**物理信道的本体容量**（decoder-independent），需要将 FB 的影响分离出来。可能的研究方向：

```
(a) FB 参数扫描:
    - 子带数: 1, 3, 5, 7, 10
    - 截止频率间隔: 4, 6, 8, 10, 12 Hz
    - 权重指数: -0.5, -1.0, -1.25, -1.5, -2.0
    → 观察准确率/MI 如何随 FB 配置变化
    → 分离 "FB 增益" vs "物理信道容量"

(b) 单子带对照:
    - 仅用 FB0 (8-90 Hz) 对比 5 子带
    → FB0 是最接近 "原始信道" 的 FB 方法（因为它覆盖所有谐波）
    → 额外子带的增益 = FB 引入的信息增益 vs 降噪增益

(c) 频率依赖性验证:
    - 滤波器组增益比预测高频目标获益更多
    → 验证: 40 个频率的准确率排序是否与 FB 增益排序相关?
    → 如果相关 → FB 是主要驱动因素
    → 如果不相关 → 物理 SNR 差异才是主因

(d) 子带权重的信息论优化:
    - 当前权重 w(k) = (k+1)^{-1.25} + 0.25 是启发式的
    - 是否存在最优权重使 MI 最大化?
    → 这等价于问: 各次谐波携带多少信息?
```

### 5.3 HD200 特殊考虑

HD200 的缓存数据 (`filtered_S{n}_200target_66ch_18blocks_float32.npy`) 的第 5 轴是 filter_bank (0-4)。在本项目的 channel analysis 分析中，我们一直使用 FB0（axis 4, index 0），即 8-90 Hz 宽带。这是一个合理的折中——既去除了低频噪声，又保留了所有谐波信息，是最接近"物理信道"的 FB 配置。

但要注意：即使是 FB0，相比 CCA 的纯陷波输入，也已经做了以下改变：
- 切除了 0-6 Hz 低频（包括 alpha 节律残余）
- 在 6-8 Hz 过渡带有部分衰减（order 7 的过渡不够陡）
- 切除了 90-125 Hz 高频（对 SSVEP 无影响，但去除了肌电等高频噪声）
