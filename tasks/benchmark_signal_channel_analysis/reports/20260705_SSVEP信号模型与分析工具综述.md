## 1. 物理信号模型

### 1.1 码本结构 (Codebook)

HD200 使用联合频率-相位调制 (JFPM) 编码 40 个闪烁目标，每个目标再通过 5 个注视位置扩展到 200 个可区分目标。

**频率编码**：40 个基频密集排列于 8.0–15.8 Hz，最小间隔 Δf = 0.2 Hz：

```
f_i ∈ {8.0, 8.2, 8.4, ..., 15.6, 15.8}  (i = 1, ..., 40)
```

每个基频有 M = 5 次谐波，因此码本的总频谱占用为 8.0–79.0 Hz，包含 40 × 5 = 200 条谱线。

![码本频谱](../results/figures/fig_model_A_codebook_spectrum.png)

**上图**：码本全频谱。上面板显示 40 个基频及其 5 次谐波（共 200 条谱线），幅度按 1/m 衰减。下面板放大基频带 8–16 Hz，可以看到 40 个频率以 0.2 Hz 间隔密集排列。8 种颜色对应 8 个整数基频组 (8.x–15.x Hz)。

**关键观察**：
- 基频带仅 8 Hz 宽，却塞入了 40 个频率 → 频谱效率 = 5 freq/Hz
- 二次谐波带 (16–32 Hz) 同样密集，且与基频带不重叠
- 高次谐波带之间有交叉（例如 8.0 Hz 的四次谐波 32.0 Hz 与 10.0 Hz 的三次谐波 30.0 Hz 都在同一频段），但精确频率不同

**相位编码**：每个频率还分配了唯一的初始相位 φ_i，用于 CCA 类方法的正交参考：

```
参考信号: Y_i = [sin(2πf_i t), cos(2πf_i t), sin(4πf_i t), cos(4πf_i t), ..., sin(2πMf_i t), cos(2πMf_i t)]
```

**空间编码**：每个闪烁目标内设 5 个注视点 (R/D/L/U/C)，偏移约 0.23° 视角。这 5 个注视点共享同一闪烁频率，但由于视网膜映射位置不同，产生可区分的 EEG 响应。

### 1.3 接收信号数学模型

通道 c 在时刻 t 的 EEG 信号：

```
x_c(t) = Σ_i  α(d_ik) · s_ic(t) + n_c(t)

其中:
  s_ic(t) = Σ_m  a_cm^(i) · sin(2πm·f_i·t + φ_cm^(i))
           → 目标 i 在通道 c 的 SSVEP 响应（M 次谐波叠加）

  α(d) = 1 / (1 + d/d_0)^p
           → 视网膜灵敏度衰减函数
           → d = 注视点到目标 i 的视角距离
           → d_0 ≈ 1.5° (中央凹半径), p ≈ 1.8

  n_c(t)  → 背景 EEG (alpha 节律, 1/f 噪声, 肌电等)
```

**标准分析假设**：

```
α(d_kk) ≈ 1    (注视目标, 中央凹内)
α(d_ik) ≈ 0    (i ≠ k, 忽略外周目标)
```

**HD200 的实际情况**：

密集屏幕上，相邻目标的视角距离约 4–5°，对应 α ≈ 0.04–0.08。虽然单个邻近目标贡献很弱，但 39 个邻近目标的总贡献构成了"频率间干扰 (ICI)"——类似于通信中的邻道干扰。

**通信系统类比**：

| SSVEP-BCI | 通信系统 |
|-----------|---------|
| 40 个闪烁频率 | 40 个子载波 (OFDM) |
| 频谱间隔 0.2 Hz | 子载波间隔 |
| 视网膜灵敏度 α(d) | 天线方向图 (波束宽度) |
| 注视 = 对准目标 | 波束对准 (beam alignment) |
| 邻近目标干扰 | 邻道干扰 (ACI/ICI) |
| 5 个注视位置 | 空间复用 (spatial multiplexing) |
| TDCA 空间滤波 | 自适应波束成形 (adaptive beamforming) |
| 背景 EEG 噪声 | AWGN + 有色噪声 |

### 1.4 空间编码的物理机制

同一闪烁目标的 5 个注视位置（R/D/L/U/C 偏移 0.23°）为什么能产生可区分的 EEG？

```
注视点偏移 0.23° → 视网膜上的投影位置不同
  → 激活的视觉皮层区域略有不同（视网膜拓扑映射, retinotopy）
  → 不同枕叶神经元群参与响应
  → 头皮各电极接收到的信号拓扑分布（amplitude + phase）有微小差异
  → 这个差异 = 空间编码信息
```

**关键量化**：
- 同频不同位置的模板相关系数 r ≈ 0.81（非常相似）
- 不同频率的模板相关系数 r ≈ 0.05–0.15（非常不同）
- 空间差异比频率差异弱约一个数量级

这就是为什么频率解码容易（原始模板匹配即可达 87%），而空间解码困难（原始模板匹配仅 39–49%，chance = 20%）。

## 2. 数据表示与维度

### 2.1 原始数据张量

![数据流程与TDCA](../results/figures/fig_model_C_pipeline_tdca.png)

HD200 的预处理数据缓存为 5 阶张量：

```
Shape: (66, 185, 200, 18, 5)
        |    |    |    |   |
        |    |    |    |   └─ filter bank (FB0–FB4)
        |    |    |    └───── blocks (18 次重复)
        |    |    └────────── targets (200 个目标)
        |    └─────────────── time samples (185 @ 250Hz = 740ms)
        └──────────────────── channels (66 导联)
```

### 2.2 特征向量构造

从张量中提取每个 trial 的特征向量：

```
选择 FB0 (宽带 6–90 Hz)
  → (66, 185, 200, 18)

截取时间窗口 [35:160] (延迟 140ms 后的 500ms)
  → (66, 125, 200, 18)

对每个 trial (target k, block b):
  v = data[:, :, k, b].flatten()    → shape (66×125,) = (8250,)
  v = v - mean(v)                   → 去直流
  v = v / ||v||                     → 单位归一化

结果: 每个 trial 是 ℝ^8250 中的单位向量
```

### 2.3 模板构造 (LOBO)

Leave-One-Block-Out 交叉验证（18 folds）：

```
对 block b_test:
  T_k = (1/17) Σ_{b≠b_test} v_k^(b)    → 17 个 trial 的均值
  T_k = T_k / ||T_k||                    → 归一化

模板集: {T_1, T_2, ..., T_200}，每个 ∈ ℝ^8250
```

### 2.4 分类

```
k* = argmax_k  corr(x, T_k) = argmax_k  (x · T_k) / (||x|| · ||T_k||)
```

由于 x 和 T_k 都已归一化，corr(x, T_k) = x · T_k = Pearson 相关系数。

### 2.5 特征空间的有效维度

名义维度 8,250 远大于实际的信息维度：

| 维度类型 | 有效秩 (erank) | 含义 |
|---------|---------------|------|
| 频率轴 | 32–33 | 40 个频率模板的独立方向数 |
| 空间轴 | 132–139 | 5 个位置引入的额外独立方向 |
| 总计 | ~159 | 200 个模板的总独立方向数 |

有效秩远小于名义维度（159 << 8250），说明模板高度结构化——它们是 SSVEP 谐波响应的低维流形上的点。

## 3. 分析工具

### 3.1 模板匹配 (Template Matching)

**数学定义**：

```
score(x, T_k) = (x · T_k) / (||x|| · ||T_k||)  ∈ [-1, 1]
k* = argmax_k score(x, T_k)
```

等价于在 8250 维单位球面上找到与 x 余弦距离最近的模板。

**在本分析中的意义**：

模板匹配是最简单的**解码器无关**分析基线。它不做任何空间滤波、不做降维、不做优化——直接在原始 channel×time 空间中比较。它揭示的是**信道固有的判别力**：

- 40-class 频率准确率 ~87% (S1, 9ch) → 频率信息在原始信号中就很强
- 5-class 空间准确率 ~45% (S1, 9ch, chance=20%) → 空间信息存在但微弱
- HD-EEG (66ch) 对两者均无帮助 → 原始信号的信道容量不随导联增加

### 3.2 PCA (主成分分析)

**数学定义**：

```
目标: max_w  Var(w^T X) = max_w  w^T Σ w / w^T w
其中  Σ = Cov(X) = (1/n) Σ_i (x_i - μ)(x_i - μ)^T
解:   Σ 的特征向量（按特征值降序排列）
```

PCA 找的是**总方差最大**的投影方向。

**在本分析中的意义**：

我们用 PCA 做了多种可视化（星座图、噪声云）。但发现一个关键限制：

```
对 5 个空间位置的 90 个 trial 做 PCA:
  PC1+2 仅解释 ~11% 的总方差
  → 88% 的方差在其他方向上
  → PCA 捕获的主要是噪声方向
  → 5 个位置在 PCA 投影中完全重叠
```

**为什么 PCA 看不到空间信息？**

因为空间差异（同频位置间 r ≈ 0.81，差异 ~19%）远小于背景噪声的方差。PCA 最大化的是总方差，所以它选择了噪声主导的方向。空间信息隐藏在高维空间的特定方向上，PCA 的前几个主成分完全错过了它。

### 3.3 LDA (线性判别分析)

**数学定义**：

```
目标: max_w  w^T S_b w / w^T S_w w

其中:
  S_b = Σ_k  n_k (μ_k - μ)(μ_k - μ)^T     → 类间散度矩阵
  S_w = Σ_k  Σ_{i∈class k} (x_i - μ_k)(x_i - μ_k)^T  → 类内散度矩阵

解: S_w^{-1} S_b 的特征向量
K 个类 → 最多 K-1 个判别方向
5 个位置 → 最多 4 个 LD 轴 → 取前 2 个做可视化
```

LDA 找的是**类间分离最大、类内散度最小**的投影方向。

**在本分析中的意义**：

LDA 是解决 PCA 盲区的关键工具：

```
对同一组 90 个 trial 做 LDA:
  Between-class ratio: 87–94%
  → LDA 找到了空间差异所在的方向
  → 5 个位置在 LDA 投影中清晰分离
```

![PCA vs LDA 对比](../results/figures/fig_model_D_tools_comparison.png)

**上图**：模拟数据演示。原始数据中 5 类完全被噪声淹没（左上）；PCA 投影仍然混乱（右上）；LDA 投影成功分离 5 类（左下）。这精确对应了我们在 SSVEP 数据上的观察。

**LDA vs TDCA 的关系**：

LDA 是有监督方法——它需要标签来计算 S_b 和 S_w。在我们的分析中，LDA 用来**证明空间信息存在**，但它不能直接当解码器（200 类 × 18 trial → 过拟合）。

TDCA 是 LDA 在 SSVEP 场景下的**实用特化版**：
- 用 TRCA 框架（最大化同类 trial 间的相关性）代替直接的 Fisher 判别
- 添加时域增广（下节详述）
- 对 SSVEP 的谐波结构友好

### 3.4 t-SNE

**数学定义**：

```
高维空间: p_{ij} = (p_{j|i} + p_{i|j}) / 2n
  其中 p_{j|i} ∝ exp(-||x_i - x_j||^2 / 2σ_i^2)

低维空间: q_{ij} ∝ (1 + ||y_i - y_j||^2)^{-1}  (Student-t 分布)

目标: min KL(P || Q) = Σ_{ij} p_{ij} log(p_{ij}/q_{ij})
```

t-SNE 保持**局部邻域结构**的非线性降维。

**在本分析中的意义**：

t-SNE 揭示了 200 个目标的**层次化结构**：

- 全局尺度：40 个频率簇清晰分离
- 局部尺度：每个频率簇内的 5 个空间位置可区分
- 9ch vs 66ch：频率簇结构不变，空间子结构在 9ch 下消失

这直接验证了 hierarchical modulation 框架：频率是全局分离轴（高 SNR），空间是局部分离轴（低 SNR）。

**注意**：t-SNE 的嵌入不可逆、距离不可直接比较。它适合定性地展示聚类结构，不适合定量分析。

### 3.5 TDCA (Task-Discriminant Component Analysis)

**时域增广 (Temporal Augmentation)**：

```
原始数据:   X ∈ ℝ^{C×T}  (66 channels × T time points)

增广:       X̃ = [X(t); X(t-1); X(t-2); X(t-3); X(t-4)]
            X̃ ∈ ℝ^{(C·L)×T}  (66×5 = 330 × T)

其中 L = 5 (lag 参数, 论文中 delay order l = 4 + 原始 = 5 份)
```

**增广的物理意义**：

```
原始空间滤波器:
  y(t) = w^T · x(t),    w ∈ ℝ^66
  → 只能做通道加权（哪些电极重要）
  → 等价于 66 个单抽头空间滤波器

增广后时空滤波器:
  y(t) = w̃^T · x̃(t),    w̃ ∈ ℝ^330
  → 每个通道有 5 个时间抽头
  → 等价于 66 个 5 阶 FIR 滤波器并联：
    y_c(t) = Σ_{l=0}^{4} w_{c,l} · x_c(t-l)
  → 可以捕获通道间的相位差和时延关系
```

**为什么时域增广对空间判别至关重要？**

空间位置差异体现为视觉皮层激活区域的微小偏移 → 信号到达各电极的传播延迟不同。纯空间滤波器只能加权幅度，无法利用这个相位/延迟信息。时域增广让滤波器学到类似"ch27 的信号比 ch33 延迟 1 个采样点时，说明是 LEFT 注视"的模式。

**通信类比**：

| 纯空间滤波 | 时域增广 |
|-----------|---------|
| 单抽头波束成形 | 多抽头时空均衡器 |
| w ∈ ℝ^66 | w̃ ∈ ℝ^330 |
| 只利用空间分集 | 同时利用空间和时间分集 |
| 相当于窄带假设 | 相当于宽带信号处理 |

**Fisher 判别目标**：

```
max  w̃^T S_b w̃ / w̃^T S_w w̃
→ 在 330 维增广空间中找到最大化类间距离/类内散度的投影方向
→ 这就是 TDCA 的"匹配滤波"本质
```

### 3.6 重叠比 (Overlap Ratio)

**定义**：

```
overlap_ratio(f) = spatial_diameter(f) / min_freq_gap(f)

其中:
  spatial_diameter(f) = max_{p,q}  d_cos(T_{f,p}, T_{f,q})
    → 频率 f 的 5 个空间模板之间的最大余弦距离

  min_freq_gap(f) = min_{g≠f}  d_cos(centroid_f, centroid_g)
    → 频率 f 的质心到最近邻频率质心的余弦距离
```

**在本分析中的意义**：

重叠比是空间复用能力的核心度量：

| 重叠比 | 含义 | 通信类比 |
|--------|------|---------|
| < 1 | 空间子点完全嵌套在频率 Voronoi cell 内 | 内层星座在判决区域内 |
| ≈ 1 | 临界点 | 噪声余量为零 |
| > 1 | 空间噪声溢出到邻频 | 内层星座越界，破坏外层判决 |

**实测结果**：

| 被试 | 重叠比 (mean ± std) | 解读 |
|------|-------------------|------|
| S3 | 0.78 ± 0.14 | 几何宽松，但绝对 SNR 低 |
| S1 | 0.95 ± 0.16 | 临界点 |
| S9 | 0.99 ± 0.18 | 刚好在临界点 |
| S11 | 1.30 ± 0.22 | **全面溢出** |

## 4. 关键发现回顾

### 4.1 信道-解码器分离

| 度量 | 无滤波 (信道固有) | TDCA (解码器增强) | 增益来源 |
|------|----------------|----------------|---------|
| 频率 9ch→66ch | −0.76% | +1.32% | TDCA 利用多通道优化频率滤波 |
| 空间 9ch→66ch | −0.61% | **+15.53%** | TDCA 在高维增广空间中找到空间判别投影 |

**结论**：HD-EEG 的价值完全是解码器介导的。原始信号中，更多导联不增加可提取的信息——甚至因为噪声增加而略有下降。

### 4.2 Hierarchical Modulation 框架

```
HD200 的编码结构:
  外层星座 (频率): 40 个点，间距 ~0.77 (cosine)，高 SNR → 可靠
  内层星座 (空间): 每频率 5 个子点，间距 ~0.55-0.70 (cosine)，低 SNR → 需要匹配滤波

信号层层级:
  频率差异 >> 空间差异 >> 试次噪声变异

解码层层级:
  频率: 原始匹配即可 (~87%)
  空间: 需要 TDCA 匹配滤波 (~45% → ~75%)
  联合: 频率×空间 = 200 类 (需要 TDCA + HD-EEG)
```

### 4.3 PCA 看不到 ≠ 不存在

这是本次分析最重要的方法论发现：

```
PCA 投影: 5 个位置完全重叠 → "空间信息不存在"？
LDA 投影: 5 个位置清晰分离 → 空间信息确实存在，只是隐藏在特定判别方向上

根本原因:
  空间差异的方差 << 噪声方差
  PCA 选择最大方差方向 → 看到的是噪声
  LDA 选择最大判别比方向 → 看到的是信号

推论:
  TDCA 的工作机制类似 LDA — 找到判别方向并投影
  HD-EEG 提供更多维度给 TDCA 优化 → 更好的投影
  这就是 +15.53% 空间增益的机制
```

### 4.4 被试差异的几何解释

```
S1 (overlap ratio = 0.95):
  → 内层星座刚好嵌入外层间隙
  → TDCA 可以提取空间信息
  → 最优 N = 160

S11 (overlap ratio = 1.30):
  → 内层星座溢出到邻频区域
  → 空间复用反噬频率判别
  → 应降阶到 N = 40

机制:
  弱被试 → 更大的试次噪声 → 空间子点被噪声推到邻频 Voronoi cell
  → 不仅空间解码失败，连频率解码也被干扰
```

## 5. 讨论

### 5.1 从 OFDM 到 Hierarchical Modulation

传统 SSVEP-BCI (≤40 targets) 相当于纯 OFDM：每个子载波（频率）承载一个符号（目标 ID），频率间隔足够大以避免干扰。

HD200 (200 targets) 相当于 hierarchical modulation / layered coding：

```
外层 (Base layer): 40 个频率 = 低阶 OFDM
  → 高可靠性，低码率
  → 任何解码器都能解

内层 (Enhancement layer): 5 个空间位置 = 空间复用
  → 低可靠性，高码率
  → 需要高级解码器 (TDCA + HD-EEG) 才能解
  → 解码失败时只影响空间维度，频率解码不受影响（当 overlap ratio < 1 时）
```

这种层次化结构在通信中被广泛使用（如 DVB-T2 的分级调制、H.264 的分级编码），其核心优势是 **graceful degradation**：信道质量下降时，先丢失内层（空间），再丢失外层（频率），而非突然全部失败。

### 5.2 信道容量的物理极限

从信号模型出发，SSVEP-BCI 的信道容量受限于：

1. **频率维度**：受限于频率分辨率（需要 1/T 的最小间隔，T 为观测时间）和可用频率范围（~8-16 Hz 对 SSVEP 有效）
2. **空间维度**：受限于视网膜拓扑映射的空间分辨率（~0.23° 的注视偏移能产生多少可区分的皮层激活模式）
3. **解码器维度**：受限于训练数据量和算法的优化能力

我们的分析揭示了一个重要的不对称性：

```
频率信道容量: ≈ log2(40) = 5.3 bits（几乎已被完全利用）
空间信道容量: 理论 log2(5) = 2.3 bits（实际利用率取决于被试和解码器）
总信道容量:   理论 log2(200) = 7.6 bits，实际 ≤ 5.3 + f(decoder) bits
```

### 5.3 为什么邻近目标干扰在实践中影响不大？

虽然理论模型预测邻近目标会产生 ICI，但实验结果（40-class 频率准确率 ~87%）表明这不是主要限制因素。原因：

1. **视网膜灵敏度快速衰减**：α(5°) ≈ 0.04–0.08，邻近目标的 SSVEP 功率 << 目标
2. **频率正交性**：不同频率的 SSVEP 在时域上正交（在足够长的观测窗口内）
3. **模板匹配的频率选择性**：Pearson 相关本身就是频率匹配滤波——与目标频率不匹配的成分在积分中被抑制

真正的限制因素是**内源性 EEG 噪声**（alpha 节律、1/f 背景），而非邻近目标干扰。

### 5.4 未来方向

1. **定量验证 ICI 模型**：可以通过分析分类错误的频率分布来检验——如果 ICI 是主要干扰源，错误应该集中在频率相邻的目标上
2. **最优目标数预测**：重叠比可以预测每个被试的最优 N，这可以用于自适应 BCI 系统
3. **时域增广阶数优化**：lag=5 是否最优？可以分析不同 lag 下的判别力变化
4. **物理模型验证**：可以用 forward model（头模型 + 视网膜拓扑映射）模拟不同注视位置的 EEG 响应，与实测数据对比

### 6.6 关于 PLV 和其他时域分析

**PLV (Phase Locking Value)**：度量 trial 间在特定频率上的相位一致性。对于 SSVEP：
- 目标频率的 PLV 应该接近 1（高度锁相）
- 非目标频率的 PLV 应该接近 0
- PLV 的空间分布可能部分指示不同注视位置的拓扑差异

PLV 适合分析**通道间的相位关系**（连接性分析），但对于 SSVEP 的基础频率判别，ERP 图像中已可见的 trial 间一致性已经说明了锁相性。PLV 对**空间位置差异**的敏感度有待验证。

## 7. 混淆矩阵与决策信道分析

> 脚本: `scripts/21_confusion_matrix_demo.py`

### 7.1 混淆矩阵的计算方法

混淆矩阵 C ∈ ℝ^{N×N} 记录分类器在所有测试 trial 上的预测结果统计。对于 200 目标的 HD200 数据集：

```
计算流程:

1. 特征向量构造 (同 §2.2):
   对每个 trial (target k, block b):
     v_{k,b} = flatten(data[ch_idx, t_start:t_end, k, b])
     v_{k,b} = (v_{k,b} - mean) / ||v_{k,b}||

2. LOBO 交叉验证 (18 folds):
   对 b_test = 1, ..., 18:
     模板: T_k = mean(v_{k,b}, b ≠ b_test),  k = 1,...,200
     T_k = T_k / ||T_k||

     分类: 对每个测试 trial v_{k, b_test}:
       k* = argmax_j  v_{k, b_test} · T_j
       C[k, k*] += 1

3. 归一化 → 转移概率矩阵:
   P(Y=j | X=i) = C[i,j] / Σ_j C[i,j]
```

**关键等价关系**：归一化后的混淆矩阵就是通信理论中的**离散无记忆信道 (DMC)** 转移概率矩阵。每一行 P(Y|X=i) 是给定输入符号 i 时的输出概率分布。

### 7.2 200×200 混淆矩阵的结构

![S1 66ch 混淆矩阵](../results/figures/fig_confusion_200x200_S1_66ch.png)

**上图**：S1, 66ch, 500ms, LOBO 模板匹配的 200×200 混淆矩阵。

左面板：完整矩阵（对数刻度）。可以看到：
- **强对角线**：大部分 trial 被正确分类（暗红色主对角）
- **块对角结构**：混淆主要发生在同频率的 5 个位置之间（5×5 对角块），跨频率误判较少
- **带状副对角**：少量跨频率混淆主要发生在相邻频率之间（Δf = 0.2 Hz 最难区分）

右上面板（区域 A）：8.0 Hz 频率内 5 位置的 5×5 空间混淆矩阵。对角线值 0.17–0.78，显示空间判别在原始模板匹配下很困难。

右下面板（区域 B）：前 5 个频率 (8.0–12.0 Hz) 的 25×25 局部混淆。对角 5×5 块 = 频率内空间混淆，非对角块 = 跨频率误判。跨频率误判概率通常比频率内空间误判低 1–2 个数量级。

### 7.3 频率内空间混淆的详细分析

![S1 空间混淆](../results/figures/fig_confusion_spatial_5x5_S1.png)

**上图**：S1 在 6 个不同频率下的频率内 5×5 空间混淆矩阵。

观察：
- 空间准确率在 30–42% 之间波动（chance = 20%），说明原始模板匹配能提取部分空间信息但远未饱和
- 不同频率的空间混淆模式不同——有些频率下 U/L 位置更容易区分，有些频率下 R/D 更好
- CENTER 位置通常没有系统性优势，说明空间差异不是简单的"中心 vs 边缘"

### 7.4 从混淆矩阵到决策信道分析

混淆矩阵归一化后直接成为信道转移矩阵，可以用信息论工具量化：

```
决策信道模型:

  X ∈ {1, ..., N}  → 真实目标 (信道输入)
  Y ∈ {1, ..., N}  → 预测结果 (信道输出)
  P(Y|X)           → 混淆矩阵归一化后的行 (信道转移概率)

互信息:
  I(X;Y) = H(Y) - H(Y|X)
         = Σ_{x,y} P(x,y) log2 [P(x,y) / (P(x)·P(y))]

其中:
  P(x,y) = P(Y=y|X=x) · P(X=x)     → 联合分布
  P(x) = 1/N                          → 均匀输入假设 (实验设计保证)
  P(y) = Σ_x P(x,y)                   → 输出边际分布

信道容量上限:
  C = log2(N) = log2(200) = 7.64 bits  (完美分类器)
```

### 7.5 信息分层分解

HD200 的 200 个目标 = 40 频率 × 5 位置，可以将总 MI 分解为频率和空间两个层次：

```
频率维度 MI:
  将 200×200 矩阵按 5×5 块求和 → 40×40 频率混淆矩阵
  I_freq(X_f; Y_f) = 从 40×40 矩阵计算
  上限 = log2(40) = 5.32 bits

空间维度 MI:
  在频率正确的前提下，取对角 5×5 块的累加
  I_spatial(X_s; Y_s | X_f = Y_f) = 从累加的 5×5 矩阵计算
  上限 = log2(5) = 2.32 bits
```

**实测结果 (S1, 66ch, 500ms, 原始模板匹配)**：

| 度量 | 值 | 上限 | 利用率 |
|------|-----|------|--------|
| 总 MI | 5.20 bits | 7.64 bits | 68% |
| 频率 MI | 4.26 bits | 5.32 bits | 80% |
| 空间 MI | 0.26 bits | 2.32 bits | 11% |

**关键观察**：
- 频率信道已被利用 80%（原始模板匹配即可提取大部分频率信息）
- 空间信道仅利用 11%（几乎所有空间信息尚未被提取 → TDCA 的增益空间）
- 总 MI < 频率 MI + 空间 MI 的上限，因为跨频率误判会同时丢失两个维度的信息

### 7.6 决策信道的通信理论意义

```
通信系统类比（完整版）:

  发射端:          实验设计 (200 个目标中选择一个呈现)
  调制方式:        JFPM (联合频率-相位调制) + 空间编码
  信道:            视觉皮层 + 头皮传导 + EEG 采集噪声
  信道矩阵:        混淆矩阵 P(Y|X)
  接收端:          解码算法 (模板匹配 / TDCA / CCA)
  互信息 I(X;Y):   每次 trial 传递的平均信息量
  信道容量 C:       最优输入分布下的最大 MI (= log2(N) for 均匀输入)

决策信道 vs 物理信道:
  物理信道:    连续信号 → 连续噪声 → 无限维
  决策信道:    离散输入 → 离散输出 → N×N 矩阵
  关系:        决策信道 = 物理信道 + 解码器的联合效果
               更好的解码器 → 混淆矩阵更接近单位阵 → MI 更接近 C
```

**解码器改进的信息论视角**：

| 解码器 | 准确率 | MI (bits) | 信道利用率 |
|--------|--------|-----------|-----------|
| 模板匹配 (原始) | ~37% | ~5.2 | 68% |
| CCA | ~47% | — | — |
| FBCCA | ~63% | — | — |
| TRCA | ~90% | — | — |
| ETRCA (TDCA) | ~94% | — | — |

每种解码器对应一个不同的决策信道。更强的解码器 = 更好的信道估计与均衡 = 更低的误码率 = 更高的 MI。TDCA 的作用等价于在接收端加了一个匹配滤波器 + 均衡器，将"嘈杂信道"转化为"更清洁的信道"。
