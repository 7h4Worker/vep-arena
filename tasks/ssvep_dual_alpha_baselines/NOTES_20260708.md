## 协议

- 时间窗：`0.2:0.2:2.0`。
- 交叉验证：5-block leave-one-block-out；每折测试每类 1 个 epoch，另外 4 个 epoch 用于训练。
- ITR：40 类，`trial_seconds = window + 0.5`，与公开示例脚本一致。
- 公开 TRCA 使用 ensemble 模式；Arena 将该路径记为 `ETRCA`，非 ensemble `TRCA` 仅作为扩展。

## 与 Ke 2025 Binocular AR 的预处理差异

- Dual-Alpha 已提供 epoch 级 CSV：从每个 epoch 首样点裁剪，再应用算法对应 filter bank。
- Ke 2025 Binocular AR 为连续 BIDS-like EEG：先连续去均值、49–51 Hz notch、5–95 Hz band-pass，再按事件 onset + 0.14 s 切窗。
- 两者进入分类器后的张量形状相似，但预处理入口和滤波顺序不能混为同一协议。

## 公开代码与对照表

- `source_code/trca_process.py`：公开 ensemble TRCA，7 个 Chebyshev 子带。
- `source_code/fbdcca_process.py`：CA/BV 的公开 FBDCCA，使用双频模板、相关系数平方、固定权重和默认 5 个激活子带。
- `metadata/Classification_results_of_TRCA.csv` 与 `metadata/Classification_results_of_FBDCCA.csv`：用于均值曲线的粗粒度对照。
