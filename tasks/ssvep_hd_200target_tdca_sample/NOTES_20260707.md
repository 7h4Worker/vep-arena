# 20260707 HD-200 task structure note

## Current role

This task owns the HD-200 offline/online reproduction and analysis workflow.
It is separate from Benchmark/BETA/cVEP baseline tasks and should remain focused
on high-target-count SSVEP behavior.

## Current formal outputs

Keep these result directories as the current usable outputs:

- `results/offline_tdca_grid`
  - Full offline TDCA grid; used for target-count, channel-count, and window
    analysis.
- `results/offline_trca_grid`
  - Full offline TRCA grid for TRCA/TDCA comparison.
- `results/figures`
  - Current summary figures generated from the offline grids and online tables.
- `results/confusions`
  - Confusion matrices used by online/offline figure scripts.

## Main scripts

- `run_offline_tdca_grid.py`
  - Main TDCA offline grid runner.
- `run_offline_trca_grid.py`
  - Main TRCA offline grid runner.
- `plot_offline_tdca_grid.py`
  - Main offline ACC/ITR/channel/target figures.
- `analyze_offline_signal_features.py`
  - Signal-feature analysis; exploratory but still useful.
- `run_online_table2.py`, `run_online_highest.py`, `plot_online_table2.py`
  - Online table/figure path.
