## 1. 原始信号与 Pearson 相关的 Sample-Level 展示

### 1.1 动机

前一版报告直接给出信道矩阵 H[i,j] 的数值结果, 缺少从原始信号到相关系数再到能量谱的逐步推导。这一部分补充完整的计算链。

### 1.2 单 Trial 展示

![Raw signal exhibits](../results/figures/fig_raw_signal_exhibits.png)

**图解 (8 子图, S1/Oz/Block0/500ms)**:

- **Row 1**: 原始 EEG 波形 — 左: 目标 8.0 Hz trial, 右: 非目标 9.0 Hz trial 作为对比
- **Row 2**: 归一化 EEG 与 sin/cos 参考信号叠加 — 展示 Pearson 相关的几何含义 (两个信号的「共振」程度)
  - 8.0 Hz trial vs sin(8 Hz): r = 直接读取
  - 8.0 Hz trial vs cos(8 Hz): r = 对应正交分量
- **Row 3**: 5 次谐波的 |r| 分解 — 左: 目标 trial (各谐波均有可见响应), 右: 非目标 trial (响应微弱)
  - 目标 trial 的总能量 E = Σ(r²_sin + r²_cos) = **0.3326**
  - 非目标 trial 在同一参考频率的能量 = **0.0534**
  - 比值 = **6.2×** — 这就是 H[i,i] > H[i,j] 的来源
- **Row 4**: 完整 40 频率能量剖面 — 横轴为 40 个基频, 纵轴为 E(x, f_j), 红色标记目标频率

### 1.3 计算链总结

```
原始 EEG (µV)
  → 零均值 + 单位范数归一化
    → 与 sin(2π·h·f·t), cos(2π·h·f·t) 做 Pearson 内积 (h=1..5)
      → 平方求和 → 能量 E(x, f_j)
        → 对所有 blocks/slots 平均 → H[i,j]
```

无任何参数优化, 无空间滤波, 纯信号-频率匹配。

### 2.2 星座图随窗口的演化

![Constellation evolution](../results/figures/fig_constellation_evolution_windows.png)

**S1 的星座图演化** (PCA 基固定为 500ms):
- **200ms**: 点几乎重叠, 仅有微弱分离 → 频率分辨率 (5 Hz) 不足以区分 0.2 Hz 间距的频率
- **300ms**: 开始展开, 低频与高频分离可见
- **500ms**: 最大展开, 频率点沿 rainbow 色谱清晰排列
- **700ms (600ms)**: 略有收缩 → MI 下降

**S11**: 在所有窗口长度下星座图都高度压缩, 噪声云远大于点间距。

### 2.3 物理解释

MI 先升后降的原因:

1. **上升段 (200→500ms)**: 更长窗口 → 更高频率分辨率 → 相邻频率更易区分 → H 矩阵对角优势增强
   - 200ms → Δf = 5 Hz, 而频率间距 0.2 Hz, 严重模糊
   - 500ms → Δf = 2 Hz, 勉强分辨部分频率
   
2. **下降段 (500→700ms)**: SSVEP 响应的非平稳性 — 后段信号 SNR 下降 (注意力衰减/肌肉伪迹), 稀释了前段的高 SNR 信号。在 Gaussian MI 估计中表现为噪声协方差增大。

3. **有效秩在 500ms 后饱和**: 说明频率分辨力的收益在 500ms 已耗尽, 更长窗口无法再揭示新的维度。

### 2.4 与解码器最优窗口的对比

解码器 (TDCA) 的最优窗口通常在 200-300ms (以 ITR 计, 因为速率 60/T 项占优)。但信道 MI 的最优窗口在 500ms — 这不矛盾:
- **MI 最优**: 纯信息量最大
- **ITR 最优**: MI × 60/T 的权衡 — 短窗口信息少但速度快

这一分离本身就是通信理论的核心: 信道容量是固有的, 但吞吐量还取决于传输速率。

## 3. 导联配置的分层比较

### 3.1 星座图矩阵

![Constellation channel layers](../results/figures/fig_constellation_channel_layers.png)

**4 subjects × 4 ch configs = 16 个星座图**, PCA 基统一为 9ch 版本:

- **S1/1ch_Oz**: MI=3.66, 星座展开良好, 频率色谱清晰
- **S1/9ch**: MI=4.57 (最高), 略微更紧凑但 SIR 更好
- **S1/32ch**: MI=3.58, 开始模糊
- **S1/66ch**: MI=3.48, 进一步模糊
- **S11**: 所有配置下星座都高度压缩

### 3.2 H 矩阵对角线剖面

![H diagonal profiles](../results/figures/fig_H_diagonal_profiles.png)

对角线 H[i,i] 表示各频率的信号能量:

- **S1**: 1ch_Oz 对角线值最高且变异最大 (频率依赖性明显); 66ch 对角线平坦且低 → 多导联平均抹平了频率特异性
- **S11**: 所有配置对角线都接近平坦 → 信号微弱, 频率特异性不明显

### 3.3 关键洞察: 「接收机匹配」而非「解码器创造信息」

前一版报告的表述「TDCA 在信道固有信息基础上创造了 3-4 bits」容易误读。更准确的框架:

**通信系统类比**:
- **1ch Oz** = 单天线接收机, 直接解调
- **9ch** = 最优子阵列, 在解码器无关分析中恰好是波束最集中的配置
- **66ch** = 全天线阵列, 但没有波束成形 → 噪声天线稀释了信号天线
- **TDCA** = 自适应波束成形接收机, 从 66ch 原始观测中提取最优子空间

解码器不是「创造」信息, 而是:
1. **波束成形** (空间滤波): 从噪声导联中提取信号 → 等效于天线阵列增益
2. **匹配滤波** (校准模板): 利用先验知识 (训练 trial) 优化接收机 → 等效于信道估计后的接收机匹配
3. **充分先验输入**: TRCA/TDCA 的训练过程等价于信道估计阶段 — 更多训练数据 = 更准确的信道状态信息 (CSI)

**TRCA 不显式匹配参考频率**, 而是通过最大化 trial 间重复性来隐式学习频率-空间模式。这更像盲信道均衡 (blind equalization) — 无需知道发送信号的精确形式, 只需重复观测的统计一致性。

## 4. TRCA vs TDCA: 解码器增益的结构

### 4.1 总体对比

![TRCA vs TDCA](../results/figures/fig_trca_vs_tdca.png)

| 目标数 | TRCA ITR | TDCA ITR | TDCA 增益 |
|--------|----------|----------|----------|
| 40     | 406.4±8.2 | 434.6±5.9 | **+6.9%** |
| 80     | 388.1±11.1 | 471.1±9.2 | **+21.4%** |
| 120    | 321.9±15.6 | 469.4±14.8 | **+45.8%** |
| 160    | 307.3±14.7 | 468.8±16.8 | **+52.6%** |
| 200    | 255.7±13.1 | 424.7±17.1 | **+66.1%** |

### 4.2 关键发现

1. **TRCA 在高目标数下急剧退化**: 40→200 targets, TRCA ITR 从 406 下降到 256 (−37%), 而 TDCA 仅从 435 下降到 425 (−2%)

2. **TDCA 的核心优势是高目标数判别力**: 在 40 targets 时两者差距很小 (+6.9%), 但 TDCA 能维持准确率到 200 targets 而 TRCA 不能

3. **TDCA 的延迟增广 (delay augmentation) 是关键**: TRCA 仅使用空间维度, TDCA 额外利用了时域维度 (lag=4 的延迟增广将特征维度扩展了 4 倍)。这等价于通信中的 MIMO + 时域均衡 vs 仅 MIMO。

### 4.3 Per-Subject 对比

![Per-subject TRCA vs TDCA](../results/figures/fig_trca_vs_tdca_per_subject.png)

- **200 targets/66ch**: TDCA 对所有被试都有显著优势, 强被试 (S1) 的绝对增益更大
- **40 targets/66ch**: 差距很小, 部分被试 TRCA 接近 TDCA

### 4.4 最优窗口对比

![Optimal windows](../results/figures/fig_optimal_window_trca_tdca.png)

- TRCA 倾向于更短的最优窗口 (200-300ms) — 因为更长窗口带来的精度提升不足以补偿速率下降
- TDCA 同样偏好短窗口, 但在高目标数下更稳定

### 4.5 通信理论解读

将 TRCA/TDCA 放入接收机框架:

| 解码器 | 通信类比 | 特征空间 | 训练 = ? |
|--------|---------|---------|---------|
| 无解码器 (本报告 Part A-C) | 直接检波 | 原始频谱能量 | — |
| TRCA | 盲均衡 (blind EQ) | 空间滤波 (maximize trial reproducibility) | 信道估计 (repetitive observation) |
| TDCA | 自适应时空均衡 | 空间 + 时域 (delay augmentation + Fisher criterion) | 信道估计 + 判别优化 |

TRCA 的「先验输入」: 多次重复试验的统计一致性 → 等效于信道的重复测量 → 信道估计精度随训练 block 数提高

TDCA 的额外增益: Fisher 判别准则显式优化类间/类内方差比 → 不仅估计信道, 还在接收端做最优判决区域划分

## 5. 相位星座图

### 5.1 概念

通信中的星座图 (QAM/PSK) 在 I/Q 平面上表示, 其中 I = 同相分量, Q = 正交分量。SSVEP 的 sin/cos 相关系数自然对应 I/Q:

- **r_sin** = 信号与 sin(2πft) 的 Pearson 相关 → I 分量
- **r_cos** = 信号与 cos(2πft) 的 Pearson 相关 → Q 分量
- **|r|** = sqrt(r_sin² + r_cos²) → 幅度
- **θ** = atan2(r_cos, r_sin) → 相位

### 5.2 结果

![Phase constellation](../results/figures/fig_phase_constellation.png)

**S1 的极坐标星座**:
- 40 个频率点分布在不同的幅度和相位
- 高频与低频在相位上有系统性差异
- 噪声云主要沿径向展开 (幅度噪声 > 相位噪声)

**S11**: 所有点聚集在原点附近, 幅度极小

### 5.3 与 PSK 的对比

SSVEP 的相位星座不像 PSK 那样均匀分布在单位圆上, 而是:
- 幅度因频率而异 (低频响应更强)
- 相位不等间隔 (受 SSVEP 传导延迟影响)
- 噪声非均匀 (径向 > 角向)

这表明 SSVEP 的频率编码更接近 ASK (幅度调制) 而非 PSK (相位调制) — 信息主要编码在功率而非相位中。但刺激范式本身使用了 JFPM (联合频率-相位调制), 所以解码器匹配后的有效调制可能不同。

## 6. 综合结论

### 6.1 本报告的新发现

| 发现 | 含义 |
|------|------|
| MI 在 500ms 达峰后下降 | 信道的最优观测窗 ≠ 解码器的最优速率窗 |
| 有效秩 200ms→500ms 翻倍 | 短窗口下频率分辨力是主要瓶颈 |
| TRCA→TDCA 增益从 +7% 到 +66% | TDCA 的时域增广在高目标数下至关重要 |
| 相位星座呈径向展开 | SSVEP 信息主要在幅度而非相位 |
| 对角线剖面: 1ch > 66ch | 确认多导联平均抹平频率特异性 |

### 6.2 从「解码器创造信息」到「接收机匹配」

修正框架:

```
信道固有信息 (decoder-independent MI):
  → 1ch Oz, 500ms: 3.66 bits (S1)
  → 9ch, 500ms: 4.57 bits (S1)

接收机增益 (spatial beamforming + temporal equalization):
  → TRCA/9ch/40t: 406 bpm → ~7.0 bits/symbol (接收机增益 ~2.4 bits)
  → TDCA/66ch/200t: 425 bpm → ~5.6 bits/symbol

总信息 = 信道固有 + 接收机增益
```

接收机增益不是凭空创造, 而是:
1. 空间滤波: 从多导联混合信号中提取目标频率的最强投影 (等效于 MIMO 波束成形增益)
2. 时域利用: delay augmentation 提取 SSVEP 的时域精细结构 (等效于 ISI 信道上的均衡增益)
3. 校准先验: 训练 trial 提供信道状态信息, 使接收机能做匹配滤波
