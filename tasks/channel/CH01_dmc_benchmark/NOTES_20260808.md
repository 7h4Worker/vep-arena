## Key findings

1. **Benchmark 9ch枕区 > 64ch全头** in C_BA at short windows (0.1-0.5s)
   - 23/35 subjects benefit from channel reduction
   - Peak ITR: occ9 = 349 bits/min vs full64 = 327 bits/min at T*=0.2s
   - τ(occ9) = 0.125s vs τ(full64) = 0.351s (2.8× faster convergence)

2. **HD200 shows opposite pattern**: 66ch > 9ch consistently
   - 9ch loss correlates with target count: r = 0.91-0.99
   - 40 targets: 1-9% loss; 200 targets: 7-12% loss

3. **Spatial topology > channel count** (Benchmark posterior32 vs wholehead32)
   - Same 32 electrodes, but posterior placement gains 5-20% C_BA

4. **Method sensitivity ranking** (most sensitive to channel config first):
   - FBCCA > CCA > ECCA > TRCA > ETRCA

5. **Two channel regimes identified**:
   - Focal paradigm (Benchmark): signal rank << channel count → reduction helps
   - Dense paradigm (HD200): signal rank ~ channel count → reduction hurts
