# NOTES 2026-07-10

## Scope

Started a task-owned TDCA workflow for the 160-target MFSC SSVEP dataset. This task is separate from the HD-200 TDCA task and from the dual-frequency datasets.

## Dataset Alignment

- The dataset is downloaded at `D:/ProjData/datasets/ssvep_160target_mfsc_chen2021`.
- Readme reports 250 Hz, 9 occipital/parietal-occipital channels, trigger 1-160, and data shape `160 x 9 x 1035`.
- `reqCodeword.mat` has shape `160 x 4`.
- The reference SSVEP-pdCCA code describes the paradigm as multi-frequency sequential coding: four 1-second slots, each chosen from eight frequencies 8-15 Hz with phases `[0, 0.5pi, pi, 1.5pi, 0, 0.5pi, pi, 1.5pi]`.

## Classification Decision

Initial TDCA uses sequence references built from the four code symbols. Epochs are constructed by taking the same segment length from each of the four 1-second slots after the 0.14 s latency correction, then concatenating the four segments.

The first task run uses `n_delay=0`. Delay augmentation is deferred until the slot-concatenation baseline is validated, because applying delays naively across slot boundaries may create artifacts.
