- Dataset: Ke et al. 2025 binocular AR SSVEP epoch zips under `D:/ProjData/datasets/ssvep_binocular_ar`.
- Official MATLAB code was downloaded to `D:/ProjData/datasets/ssvep_binocular_ar/metadata/official_code_26768287_v8`.

## 2026-07-08 Supplement: Short Windows and CCA/FBCCA

Purpose:

- Add the paper's missing short windows `0.1, 0.2, 0.3, 0.4 s`.
- Add CCA and FBCCA baselines to the same task output directories.
- Keep existing TRCA/ETRCA `0.5:0.1:3.0` results and resume only missing methods/windows.

Implementation:

- `vep_arena.methods.traditional.multi_frequency_reference_signals` now builds multi-frequency CCA references by concatenating sine/cosine rows for each frequency per harmonic.
- `CCA` and `FBCCA` accept explicit reference matrices. Existing single-frequency benchmark behavior is preserved when no custom references are supplied.
- For Ke 2025 Experiment 2/3, CCA/FBCCA references follow the public MATLAB `test_fbcca.m`: `Sin(left), Cos(left), Sin(right), Cos(right)` for each harmonic, with no phase term in FBCCA.
- `run.py` now resumes at method level. A subject/task/window unit can keep previous `TRCA,ETRCA` rows and add only missing `CCA,FBCCA` rows.
- FBDCCA was not mixed into this Ke task. The suitable reproduction reference is the Dual-Alpha official source `D:/ProjData/datasets/ssvep_dual_alpha_gigadb_102557/source_code/fbdcca_process.py`, which uses squared correlations, ten FIR filter-bank bands, and dual-frequency code templates.

Paper comparison notes:

- The paper reports windows `0.1-3.0 s`, ITR peaks around `0.4-0.6 s`, and binocular-incongruent conditions above 92% after `0.5 s` with peak TDCA ITR around 90-105 bits/min.
- The local TRCA/ETRCA results match this broad pattern in the strongest dual-frequency conditions: DFDP, DFDP3, and DFDP1 reach high accuracy and peak ITR in the expected short-window range.
- CCA/FBCCA are much weaker than TRCA/ETRCA for several dual-frequency conditions, especially at `0.5 s`. This is directionally consistent with the paper's statement that training-based methods outperform FBCCA, but exact FBCCA agreement still depends on bitwise preprocessing and MATLAB `canoncorr` differences.
