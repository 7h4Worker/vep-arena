# NOTES 2026-07-17

## Scope

Moved the Sun2024 task from event/CCA smoke toward the paper's formal
classification path. The relevant paper method is bTRCA/ebTRCA for binocular
dual-frequency targets, with TRCA/eTRCA as baselines.

## Paper Alignment

- The paper describes the 40-target offline split as 5 trials per target, 200
  trials total, with leave-one-out cross-validation. The local CNT files are
  mixed: subjects 1-9 have 320 usable 40-target trials in 8 blocks, while
  subjects 10-14 have 200 usable trials in 5 blocks.
- The Excel codebook contains left/right-eye frequencies only. The 40 targets
  form 20 unordered frequency pairs; each pair appears twice with the two
  frequencies swapped between eyes.
- `run_formal.py` uses leave-one-block-out cross-validation.
- Default epoching follows the acquisition reduction by resampling to 250 Hz,
  but the current preprocessing uses notch filtering plus Butterworth
  filter-bank bands. The paper states that 40-target offline/online data used
  comb filtering, so this remains a known mismatch.
- The ITR calculation includes a configurable target-search time, defaulting to
  0.5 s as described in the paper.

## Implementation Note

Added `vep_arena.methods.btrca.BTRCA`. The current Arena implementation follows
the bTRCA swapped-target idea: for each swapped pair, it estimates a shared
cross-target covariance numerator and target-specific within-class covariance
denominators, then scores projected test trials against EEG templates. ebTRCA is
implemented by using the ensemble of all fitted bTRCA spatial filters during
scoring, matching the eTRCA-style extension described in the paper.

This is a first formal Arena implementation from the paper equations and local
codebook structure. If original author code becomes available, compare the
covariance construction and filter-bank/comb-filter details before treating the
numbers as exact author-code reproduction.

## bTRCA Covariance Correction

After the first formal smoke, TRCA/eTRCA were plausible but bTRCA/ebTRCA were near chance. Rechecking Eq. (9) showed the denominator should pool the noise covariance across all targets in group O or group S, not only the current target. `vep_arena.methods.btrca.BTRCA.fit` was corrected to use group-level pooled noise covariance and pair-level summed cross-trial covariance. The current O/S assignment uses the lower trigger in each swapped frequency pair as O because the public Excel codebook does not mark the burgundy/blue figure groups explicitly.

## Reproduction Audit After Full Occipital9 Run

The full `formal_full_20260717_occipital9` run completed, but it is not a
paper-level reproduction. See `REPORT_20260717_REPRO_AUDIT.md`.

Key reasons:

- The paper used all 64 leads; this run used `occipital9`.
- The paper states that 40-target analyses used comb filtering; this run used a
  notch plus Butterworth filter-bank approximation.
- The paper text reviewed so far does not explicitly document a 140 ms latency
  crop; this run used `--onset-shift 0.14`.
- The paper bTRCA equations use filter matrices and O/S groups; the current
  implementation uses a leading-vector approximation and infers O/S from the
  lower trigger in each swapped pair.
- The local trial/block counts differ from the paper's stated 200-trial offline
  protocol for subjects 1-9.

Immediate diagnostic evidence:

- All-channel subject 1, 0.6 s, two-fold smoke improved EBTRCA to 0.8500,
  compared with 0.7500 in the comparable occipital9 smoke.
- All-channel subject 1 with `--onset-shift 0` reduced EBTRCA to 0.7250, so
  the 0.14 s crop currently helps but remains an implementation assumption.

## Comb-Filter Implementation

Added `vep_arena.signal.filters.powerline_comb_filter` and exposed
`run_formal.py --preprocess comb_filterbank`. This mode removes the channel-wise
DC offset, applies a zero-phase `scipy.signal.iircomb` notch comb, and then runs
the existing TRCA-style sub-band filters because the paper states that bTRCA
operations are still weighted across frequency bands.

The public PDF does not specify comb filter parameters. The current audit
default is `--comb-f0 50 --comb-q 35`; both values are written to the run
manifest and should be replaced if author code or supplementary material gives
the exact setting.

The runner also adds `--max-blocks 5` so subjects 1-9 can be restricted from
the local 8-block files to the paper's stated 5 trials per target before
leave-one-block-out cross-validation. This is different from `--max-folds`,
which only limits which held-out folds are evaluated and leaves later blocks in
the training set.

All-channel CNT loading initially failed under concurrent Liang2020 load
because `raw.copy().pick_types()` duplicated the preloaded recording. The
runner now selects EEG channels from `raw.info`, opens CNT with `preload=False`,
crops to the requested trial range with `--crop-padding 5`, then loads and
resamples the smaller segment.

## Plotting Alignment

The first plot pass mixed smoke settings in a single global figure, which was
not aligned with the other Arena tasks. Plotting has been revised:

- formal plots are generated per run via `plot_acc_itr.py --run <run_name>`;
- outputs are written into the selected run directory as `figures/accuracy_curve.png`,
  `figures/itr_curve.png`, `figures/accuracy_heatmap.png`, `figures/subject_box_best.png`;
- `subject.csv`, `summary_aggregate.csv`, and `report.md` are generated beside
  the original runner `summary.csv`;
- smoke comparisons require explicit `--include-smoke` and are written under
  `results/diagnostics/`.
