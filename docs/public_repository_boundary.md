# Public 仓库披露边界

VEP Arena 是 public 仓库。推送的 branch、Draft PR、review、issue 和 comment 均视为公开披露。

## 可以进入版本控制的内容

- 可复用源码模块与测试；
- task runner 与绘图源码；
- 数据集元数据、公开下载链接、许可和匿名标识；
- 从已发表论文或公开参考代码整理的协议记录；
- 明确标注实现身份和复现限制的技术说明。

## 只保留在本地的内容

- 原始、预处理或派生 EEG 数组；
- 受试者身份映射和原始实验记录；
- 生成的 CSV、NPZ、NPY、MAT、图片、报告、checkpoint 与日志；
- 未发表假设、分析、跨范式结论和论文草稿结论；
- 尚未获得所有者批准公开的代码。

关闭 PR 或删除远端 branch 不能撤销已经发生的公开披露。本地专属内容不得推送到 public remote。

## 复现实现身份

论文衍生实现必须标记为以下一种身份：

- `official-code reproduction`：直接运行或直接移植作者公开代码；
- `paper-spec reproduction`：依据已发表公式与协议重新实现；
- `Arena adaptation`：在 Arena 特定接口或协议下复用公开方法；
- `diagnostic`：只用于定位行为，不作为论文复现证据。

数据集 task 必须记录来源论文、公开数据记录与许可、通道和事件映射、采样率、预处理、评估单元以及未解决歧义。方法模块应在相关实现附近引用来源论文，并说明实质性偏差。
